DeepChem provides an end-to-end toolkit for drug discovery workflows, from featurizing raw SMILES strings to training state-of-the-art graph neural networks that predict ADMET properties, toxicity endpoints, and binding affinities. By combining MoleculeNet's curated datasets with models like `GCNModel` and `GATModel`, you can build rigorous screening pipelines that generalize across chemical space.

## Toxicity classification with Tox21

The Tox21 dataset contains qualitative toxicity measurements for ~8,000 compounds across 12 nuclear receptor and stress response assays. It is the standard benchmark for multi-task molecular classification.

<Steps>
  <Step title="Load the Tox21 dataset">
    Use `dc.molnet.load_tox21()` with a graph featurizer. MoleculeNet handles downloading, featurizing, and caching automatically.

    ```python
    import deepchem as dc

    featurizer = dc.feat.MolGraphConvFeaturizer(use_edges=True)
    tasks, datasets, transformers = dc.molnet.load_tox21(
        featurizer=featurizer,
        splitter='scaffold',
        transformers=['balancing'],
    )
    train_dataset, valid_dataset, test_dataset = datasets
    print(tasks)
    # ['NR-AR', 'NR-AR-LBD', 'NR-AhR', 'NR-Aromatase', 'NR-ER',
    #  'NR-ER-LBD', 'NR-PPAR-gamma', 'SR-ARE', 'SR-ATAD5',
    #  'SR-HSE', 'SR-MMP', 'SR-p53']
    ```
  </Step>
  <Step title="Apply ScaffoldSplitter for realistic evaluation">
    Passing `splitter='scaffold'` to `load_tox21()` uses `ScaffoldSplitter` internally. This splits molecules by Murcko scaffold so that train and test sets share no common chemical scaffolds — a stricter generalization test than random splitting.

    <Note>
      The Tox21 source documentation recommends random splitting, but scaffold splitting is preferred when evaluating model generalization to novel chemotypes.
    </Note>
  </Step>
  <Step title="Train a GCNModel">
    `GCNModel` wraps the DGL-based `GCN` module. Set `mode='classification'` for binary toxicity labels and provide the number of tasks.

    ```python
    model = dc.models.GCNModel(
        n_tasks=len(tasks),
        mode='classification',
        learning_rate=0.001,
    )
    model.fit(train_dataset, nb_epoch=50)
    ```
  </Step>
  <Step title="Evaluate with ROC-AUC">
    ```python
    metric = dc.metrics.Metric(dc.metrics.roc_auc_score, np.mean)

    train_scores = model.evaluate(train_dataset, [metric], transformers)
    test_scores  = model.evaluate(test_dataset,  [metric], transformers)

    print("Train ROC-AUC:", train_scores)
    print("Test  ROC-AUC:", test_scores)
    ```
  </Step>
</Steps>

### Full Tox21 classification example

```python
import numpy as np
import deepchem as dc

# 1. Featurize and load with scaffold split + balancing transformer
featurizer = dc.feat.MolGraphConvFeaturizer(use_edges=True)
tasks, datasets, transformers = dc.molnet.load_tox21(
    featurizer=featurizer,
    splitter='scaffold',
    transformers=['balancing'],
)
train_dataset, valid_dataset, test_dataset = datasets

# 2. Train GCNModel for multi-task binary classification
model = dc.models.GCNModel(
    n_tasks=len(tasks),
    mode='classification',
    learning_rate=0.001,
    batch_size=64,
)
model.fit(train_dataset, nb_epoch=50)

# 3. Evaluate
metric = dc.metrics.Metric(dc.metrics.roc_auc_score, np.mean)
print("Test ROC-AUC:", model.evaluate(test_dataset, [metric], transformers))
```

## Binding affinity regression with BACE

The BACE dataset provides pIC50 binding affinity measurements for 1,522 inhibitors of human beta-secretase 1 (BACE-1), a key target in Alzheimer's disease research. Use `load_bace_regression()` for the continuous `pIC50` label.

```python
import deepchem as dc

featurizer = dc.feat.MolGraphConvFeaturizer(use_edges=True)
tasks, datasets, transformers = dc.molnet.load_bace_regression(
    featurizer=featurizer,
    splitter='scaffold',
    transformers=['normalization'],
)
train_dataset, valid_dataset, test_dataset = datasets
# tasks == ['pIC50']

model = dc.models.GATModel(
    n_tasks=len(tasks),
    mode='regression',
    learning_rate=0.001,
)
model.fit(train_dataset, nb_epoch=100)

metric = dc.metrics.Metric(dc.metrics.pearsonr, np.mean)
print("Test Pearson r:", model.evaluate(test_dataset, [metric], transformers))
```

<Tip>
  For the binary inhibitor classification variant, use `dc.molnet.load_bace_classification()`, which targets the `Class` column and applies `BalancingTransformer` by default.
</Tip>

## ADMET property prediction workflow

ADMET (absorption, distribution, metabolism, excretion, toxicity) screening covers multiple endpoints simultaneously. The workflow below applies to any MoleculeNet dataset that provides multi-task labels.

```python
import deepchem as dc

# Replace with your multi-task ADMET dataset
featurizer = dc.feat.MolGraphConvFeaturizer(use_edges=True)
tasks, datasets, transformers = dc.molnet.load_tox21(
    featurizer=featurizer,
    splitter='scaffold',
    transformers=['balancing'],
)
train_dataset, valid_dataset, test_dataset = datasets

# GCNModel handles missing labels (NaN) via masking automatically
model = dc.models.GCNModel(
    n_tasks=len(tasks),
    mode='classification',
    learning_rate=5e-4,
    batch_size=128,
)
model.fit(train_dataset, nb_epoch=100)
```

<Note>
  Tox21 labels are sparse — many compounds lack measurements for some assays. DeepChem's graph models mask missing labels during training, so no manual imputation is needed.
</Note>

## Models for drug discovery

<CardGroup cols={2}>
  <Card title="GCNModel" icon="circle-nodes">
    Graph Convolutional Network. Shared learnable weights across all nodes. Good baseline for classification and regression on molecular graphs. Requires DGL and DGL-LifeSci.
  </Card>
  <Card title="GATModel" icon="diagram-project">
    Graph Attention Network. Uses multi-head attention over neighbor nodes, weighted by learned attention coefficients. Often outperforms GCN on heterogeneous datasets.
  </Card>
  <Card title="AttentiveFPModel" icon="magnifying-glass">
    Attentive fingerprint model that uses a graph attention mechanism to produce task-specific molecular fingerprints. Strong performance on MoleculeNet benchmarks.
  </Card>
  <Card title="DMPNNModel" icon="route">
    Directed Message Passing Neural Network. Aggregates messages along directed edges, reducing over-smoothing. State-of-the-art on many property prediction tasks.
  </Card>
  <Card title="ChemBERTa" icon="language">
    Transformer pretrained on SMILES strings. Fine-tune on downstream tasks with limited labeled data. Loaded via the HuggingFace model hub integration in DeepChem.
  </Card>
</CardGroup>

<Tip>
  When your dataset has severe class imbalance (e.g., &lt;5% positives in some Tox21 assays), pass `transformers=['balancing']` to `load_tox21()`. This applies `BalancingTransformer`, which reweights samples so that the effective positive/negative ratio is 1:1 during training without discarding any data.
</Tip>
