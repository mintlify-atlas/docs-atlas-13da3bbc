## Get started in 4 steps

<Steps>
  <Step title="Install DeepChem">
    Install the core library with your preferred deep learning backend:
    ```bash
    pip install deepchem
    # For PyTorch support:
    pip install deepchem[torch]
    ```
  </Step>
  <Step title="Load a dataset">
    Use MoleculeNet to load a benchmark dataset with automatic featurization and splitting:
    ```python
    import deepchem as dc
    tasks, datasets, transformers = dc.molnet.load_tox21()
    train_dataset, valid_dataset, test_dataset = datasets
    ```
  </Step>
  <Step title="Train a model">
    Train a graph convolutional network on the loaded data:
    ```python
    model = dc.models.GCNModel(n_tasks=len(tasks), mode='classification')
    model.fit(train_dataset, nb_epoch=50)
    ```
  </Step>
  <Step title="Evaluate performance">
    Measure model performance with standard metrics:
    ```python
    metric = dc.metrics.Metric(dc.metrics.roc_auc_score)
    results = model.evaluate(test_dataset, [metric], transformers)
    print(results)
    ```
  </Step>
</Steps>

## MoleculeNet benchmarks

DeepChem ships with [MoleculeNet](/moleculenet/overview), a curated collection of 40+ datasets spanning molecular properties, toxicity, quantum chemistry, and biophysics — making it easy to benchmark models and reproduce results from the literature.

<Note>
  DeepChem supports Python 3.7–3.12. For GPU acceleration, install CUDA before installing your preferred deep learning framework.
</Note>
