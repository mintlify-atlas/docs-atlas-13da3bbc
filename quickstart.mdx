DeepChem makes it possible to go from a raw molecular dataset to a trained graph neural network in just a few lines of Python. This guide walks through the core workflow: loading the Tox21 benchmark dataset via MoleculeNet, training a Graph Convolutional Network, and evaluating it with the ROC-AUC metric. No manual featurization or data wrangling is required—DeepChem handles all of it.

## Steps

<Steps>
  <Step title="Install DeepChem with PyTorch">
    Install DeepChem with the PyTorch backend. This pulls in `torch`, `pytorch-lightning`, `dgl`, and `dgllife` alongside the core DeepChem package.

    ```bash
    pip install 'deepchem[torch]'
    ```

    <Note>
    In `zsh`, wrap the argument in quotes to prevent the shell from interpreting the square brackets as a glob pattern.
    </Note>
  </Step>

  <Step title="Load a MoleculeNet dataset">
    `deepchem.molnet.load_tox21` downloads the Tox21 dataset, featurizes each molecule as a molecular graph, and returns pre-split train, validation, and test `Dataset` objects.

    ```python
    import deepchem as dc

    tasks, datasets, transformers = dc.molnet.load_tox21(featurizer='GraphConv')
    train_dataset, valid_dataset, test_dataset = datasets
    ```

    `tasks` is a list of the 12 toxicology endpoint names. `transformers` contains any `NormalizationTransformer` or `BalancingTransformer` objects that were applied to the labels—you will need them when evaluating.
  </Step>

  <Step title="Train a GCNModel">
    `deepchem.models.GCNModel` is a graph convolutional network implemented in PyTorch. Pass the number of tasks and set `mode='classification'` for binary toxicity prediction.

    ```python
    model = dc.models.GCNModel(
        n_tasks=len(tasks),
        mode='classification',
        learning_rate=0.001,
    )
    model.fit(train_dataset, nb_epoch=50)
    ```

    `fit` runs the training loop and returns the average loss. Increase `nb_epoch` or tune `learning_rate` to improve convergence.
  </Step>

  <Step title="Evaluate with ROC-AUC">
    Wrap `deepchem.metrics.roc_auc_score` in a `Metric` object and call `model.evaluate` on each split. Pass `transformers` so that the predictions are un-transformed before scoring.

    ```python
    metric = dc.metrics.Metric(dc.metrics.roc_auc_score)

    train_scores = model.evaluate(train_dataset, [metric], transformers)
    test_scores  = model.evaluate(test_dataset,  [metric], transformers)

    print("Train ROC-AUC:", train_scores)
    print("Test  ROC-AUC:", test_scores)
    ```
  </Step>
</Steps>

## Complete example

The full workflow in one block:

```python
import deepchem as dc

# 1. Load Tox21 with graph featurization
tasks, datasets, transformers = dc.molnet.load_tox21(featurizer='GraphConv')
train_dataset, valid_dataset, test_dataset = datasets

# 2. Build and train a Graph Convolutional Network
model = dc.models.GCNModel(
    n_tasks=len(tasks),
    mode='classification',
    learning_rate=0.001,
)
model.fit(train_dataset, nb_epoch=50)

# 3. Evaluate on train and test splits
metric = dc.metrics.Metric(dc.metrics.roc_auc_score)
train_scores = model.evaluate(train_dataset, [metric], transformers)
test_scores  = model.evaluate(test_dataset,  [metric], transformers)

print("Train ROC-AUC:", train_scores)
print("Test  ROC-AUC:", test_scores)
```

## What each part does

**`dc.molnet.load_tox21`** — One of over 40 dataset loaders in `deepchem.molnet`. It downloads the raw CSV, converts each SMILES string to a molecular graph using `MolGraphConvFeaturizer`, applies a `BalancingTransformer` to address class imbalance, and splits the data by scaffold. The return value is a tuple of `(tasks, (train, valid, test), transformers)`.

**`dc.models.GCNModel`** — A PyTorch implementation of a graph convolutional network. The model aggregates atom and bond features through several graph convolutional layers before passing the graph-level representation through a fully connected head. Setting `mode='classification'` attaches a sigmoid output and uses binary cross-entropy loss.

**`dc.metrics.Metric`** — A thin wrapper that pairs a score function with configuration (task averaging strategy, threshold, etc.). `dc.metrics.roc_auc_score` is re-exported from scikit-learn and operates per task before averaging across the 12 Tox21 endpoints.

**`model.evaluate`** — Calls `model.predict` on the dataset, un-transforms the predictions using the supplied `transformers`, and computes the metric for each task. The result is a dictionary mapping metric names to scores.
